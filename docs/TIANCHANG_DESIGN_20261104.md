# 天长观 · Tianchang Temple

设计日期：2026-11-04（瑞士时间）。项目：Wish Code 道教文化游戏网站。

## 当前决定

- 入口：现有 wishcode.ch 首页动态卡片；子路径 `/tianchang/`，不购买新域名。
- 角色：男、女访客两种卡通形象；功能相同，支持昵称及衣色。
- 空间：白云观的院落与中轴动线为建筑参考，三清山山水为外部意境，属于艺术融合，不是官方数字分观或精确测绘复原。
- 主殿：三清合祀，元始天尊居中。本版本面向神龛时，道德天尊在画面左、灵宝天尊在画面右。
- 主打功课：《太上老君说常清静经》。本版使用泰山明万历碑刻的官方刊载正文，依其异文，不混合不同版本；阅读分八段，不包含附赞。
- 免费入场、静坐、诵读、舒展；许愿、抽签、上香、点灯设置自愿随喜，金额由用户自主选择，可不贡献继续体验。金额不影响结果，不设“功德排行榜”。
- 随喜原型只记录意向；尚未连接收款方与支付渠道，没有扣费、付款凭证或捐赠收据。

## 录屏项目分析

用户提供约50秒录屏。可见：林间庭院、主殿与佛像、卡通僧人、蒲团、参拜、木鱼、念珠和音效控制。外部查证名称为 Sansa（산사，sansatemple.com）。官方首页介绍为拨动念珠、礼拜、短暂休息的线上空间；Korea Herald 2026-11-01 报道其匿名角色与无聊天机制。

值得借鉴的是低门槛进入、仪式动作、空间氛围与安静的陪伴感。用户规模仅有新闻报道，未独立核验后台；没有收入或长期留存证据。视频不能证明代码架构、多人同步的具体实现或商业化能力。

天长观采用独立道教叙事：束发与交领衣袍、三清尊神、《清静经》、随喜敬香点灯、许愿与行动、还愿与感恩。保留 Wish Code 三数字心愿入口，并链接其既有九语起卦功能。

## 入场镜头与游戏循环

1. Wish Code：首页动态云山入口，九语入口说明随既有语言切换。
2. 访客选择：男女角色，入场免费，约12秒动画，可跳过。
3. 远山镜头：长石阶、云海、远处道观，镜头缓慢推近。
4. 上山镜头：向石阶上方推进，渐入白云观式庭院。
5. 山门镜头：双门以透视轴缓缓打开；跨过门槛。
6. 入殿镜头：镜头穿门，三清主殿出现，交回玩家控制。
7. 自由参访：轻点地面 / WASD / 方向键移动；庭院、大殿、太极云台切换。
8. 核心循环：入观 → 安顿身心 → 表达心愿 → 一步行动 → 再访还愿。

本版为单人2.5D交互：原创场景图、CSS透视门扇、角色移动、动画和本地交互。不是实时全3D场景、自由摄像机或多人在线世界；不伪造在线人数。

## 入观规则

从公开礼仪抽取轻声、慢行、整洁、礼敬经像、指定区域敬香与摄影许可等原则；不把出家道众清规的处罚条款套用于游客。男女访客功能一致。原经文阴阳、男女表述作为古籍保留，并解释不作现代性别评价。

设计规则：不攻击神像、无破坏互动、不骚扰、不拉客、不冒充道长或官方；不强索供养，不按金额划分“灵验等级”。普通访客可静观，不强制拜礼。实体场所具体规定以其现场告示为准。

## 下一阶段

1. 文化校审：邀请合适道教顾问审阅神像图像、科仪称谓、经文底本与礼仪；合作方尚未确认。
2. 音频：取得授权的《清静经》真实诵唱录音；当前设备语音只是原型朗读，不能称为道长诵唱。
3. 后台与支付：明确运营主体、实际收款方、贡献用途与退款处理后接入支付；只在支付成功回执后记实收。
4. 法事实务：受理、报价/随喜确认、预约、执行说明、回执，必须由真实合作道观承接，不生成虚构完成状态。
5. 多人场景：再设计房间同步、可见性与举报机制；首版未连接多人服务器。
